# docs/srs

ต้นฉบับจากบทเรียนก่อนหน้า (วัตถุดิบของ spec.md) ใช้อ้างอิงเมื่อ spec.md ไม่ชัด

| ไฟล์ | คืออะไร | มาจากบทเรียน |
|---|---|---|
| catalogue.md | ข้อความต้นฉบับของ REQ ทุกข้อที่ UC-07 แตะ (3 ข้อที่ใช้ทุก feature ย้ายข้อความไปไว้ที่ specs/000-shared/constraints.md ตาม CR-04) | Requirements Catalogue |
| UC-07.md | use case fully dressed | Use Case และ Acceptance Criteria |
| glossary.md | คำที่ใช้ได้ และชื่อในโค้ด | Living Specification |
| baseline.md | Baseline B2 (ด้านบน) บันทึกเดิมของ B1 กติกาเปลี่ยนแปลง และตาราง CR | Living Specification และ Verification, Traceability และ Change |

กฎธุรกิจ (BR-01..03) และโมเดล (MD-xx) ที่ feature นี้ใช้ อยู่ใน specs/002-booking/rules.md และ models.md
